## Builders

All implement `SnackyBuilder`:

- `SimpleSnackyBuilder` — default card layout. Hooks: `backgroundColorBuilder`,
  `iconColorBuilder`, `iconBuilder`, `borderBuilder`, `textStyleBuilder`
  (`SimpleSnackyTextType`), `closeIconBuilder`, `shadowBuilder`, `disableInkwell`,
  `margin`, `padding`, `borderRadius`.
- `ToastSnackyBuilder` — centered pill. Hooks: `backgroundColorBuilder`,
  `borderBuilder`, `textStyleBuilder` (`ToastSnackyTextType`), `margin`,
  `padding`, `borderRadius`.
- `GradientSnackyBuilder` — dark card with gradient icon glow. Hooks:
  `backgroundColorBuilder`, `iconColorBuilder`, `iconBuilder`, `borderBuilder`,
  `textStyleBuilder` (`GradientSnackyTextType`), `disableInkwell`, `margin`,
  `padding`, `borderRadius`.

Write a custom one by extending `SnackyBuilder` and implementing
`build(context, layoutConfig, cancelableSnacky, snackyController)`. Wrap your
content in `BaseSnackyWidget` to inherit the framework behaviors.

## BaseSnackyWidget

The shared foundation used by every built-in builder. It provides the slide
transition, safe area, swipe-to-dismiss, and tap handling, and renders your
content via `customBuilder`. See [Builders & Theming](/guides/builders#building-on-basesnackywidget).

| Parameter          | Type                                              | Default               |
| ------------------ | ------------------------------------------------- | --------------------- |
| `cancelableSnacky` | `CancelableSnacky`                                | —                     |
| `snackyController` | `SnackyController`                                | —                     |
| `layoutConfig`     | `SnackyLayoutConfig`                              | —                     |
| `customBuilder`    | `Widget Function(BuildContext, CancelableSnacky)` | —                     |
| `borderRadius`     | `BorderRadius`                                    | `BorderRadius.zero`   |
| `margin`           | `EdgeInsetsGeometry`                              | `EdgeInsets.all(16)`  |
| `width`            | `double?`                                         | `null`                |
| `disableInkWell`   | `bool`                                            | `false`               |

## CancelableSnacky

| Member            | Description                                  |
| ----------------- | -------------------------------------------- |
| `snacky`          | The wrapped `Snacky`.                        |
| `cancel()`        | Dismiss this snacky.                         |
| `isCancelled`     | Whether it has been cancelled.               |
| `isNotCancelled`  | Convenience inverse of `isCancelled`.        |

## SnackyNavigationObserver

A `NavigatorObserver` that calls `cancelAll()` on `didPush` and `didReplace`.
Optional `snackyController` (defaults to the singleton).
